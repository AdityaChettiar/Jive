# Class Calendar as a Fixed Anchor

**Status:** Proposed; import methods and schedule rules need discussion.

## Idea

Let a student provide their class schedule, either by importing it from an LMS or uploading a screenshot. Treat class periods as fixed commitments and build the rest of the day around them.

## Questions to resolve

- Which LMS or calendar formats matter for the first audience?
- Is screenshot upload a fallback, or the expected starting method?
- How should the app handle extraction errors, timetable changes, and recurring classes?
- Can students review and correct an imported schedule before it is used?
- Are travel time, breaks, and preparation time part of the fixed schedule?
