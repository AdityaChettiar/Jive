# Ideas

This folder contains one Markdown file for each product idea or substantial concept discussed for Jive. These notes are discovery artifacts, not implementation specifications unless a decision is explicitly marked as agreed.

Use numbered filenames in discussion order. Keep assumptions, decisions, and open questions distinct. Update the root README and relevant folder README files when high-level direction changes.

## Ideas

- [001 — Goal planner discovery](001-student-planner-discovery.md): evolving product framing and interview questions.
- [002 — Class calendar as a fixed anchor](002-class-calendar-import.md): import a class timetable from an LMS or screenshot.
- [003 — One plan across life areas](003-integrated-daily-planning.md): coordinate academics, gym, diet, habits, and content creation.
- [004 — Schedule around workload and energy](004-energy-aware-scheduling.md): shape task duration and placement around backlogs and energy.
- [005 — User priorities and changing contexts](005-custom-priorities.md): customize priorities for free time, exams, vacations, and other events.
- [006 — Reschedule when tomorrow changes](006-dynamic-rescheduling.md): tell an assistant about changes and re-plan around them.
- [007 — Onboarding and personal context](007-onboarding-and-personal-context.md): gather routine, workable time, interests, and preferences.
- [008 — Conversational goal clarification](008-conversational-goal-clarification.md): use dialogue to turn broad ambitions into specific outcomes.
- [009 — Goal programmes and daily actions](009-goal-programmes-and-daily-actions.md): structure steps into a realistic programme and daily tasks.
- [010 — Accountability with friends](010-social-accountability.md): streaks and small groups for mutual progress tracking.
- [011 — Connect people with shared interests](011-interest-based-connections.md): help users find others learning or working in similar areas.
- [012 — Nutrition aligned with activity](012-nutrition-support.md): eventually relate meal guidance to planned activity and energy needs.
- [013 — Check-in feedback and plan calibration](013-check-in-feedback-and-plan-calibration.md): use reports about the plan to improve future schedules while keeping goals meaningful.
- [014 — Conversational feedback space](014-conversational-feedback-space.md): make freeform conversation the primary way to share context and feedback, with structured prompts as a supplement.
- [015 — Visual recommendations with approval](015-visual-recommendations-and-approval.md): compare solution trade-offs, recommend a fit, and wait for approval before changing the schedule.
- [016 — Conversational change negotiation](016-conversational-change-negotiation.md): revise proposed changes together while preserving the user's final say.
- [017 — Replanning cadence and progress focus](017-replanning-cadence-and-progress-focus.md): support schedule history and revisions while discouraging frequent replanning that substitutes for action.
- [018 — Progress signals and goal milestones](018-progress-signals-and-goal-milestones.md): combine consistent activity streaks with goal-specific evidence and milestones.
- [019 — Phased goal journeys](019-phased-goal-journeys.md): preview the overall path while detailing only the user's current phase.
- [020 — Progress-aware coaching check-ins](020-progress-aware-coaching-check-ins.md): discuss pending work and blockers supportively, then help the user adjust.
- [021 — Overdue alerts and persistent blockers](021-overdue-alerts-and-persistent-blockers.md): notify about prolonged unfinished work and track unresolved progress problems for later design.
