# Backend

Planned home for Jive's server-side behavior and data services. This folder is documentation only; no framework, API, or database has been selected or created.

## High-level direction

Backend needs will follow from agreed product requirements. Candidate needs include storing routines, goals, schedules, plan feedback, and plan changes; social features are only exploratory. A local SQL database is a possible later option, not a current decision. Data ownership, persistence, authentication, and deployment remain open questions.

## Current status

Discovery only. See the root [README](../README.md) and [`ideas/`](../ideas/README.md) for current context and interview notes. Do not begin implementation until the product owner and Codex have agreed on the approach.
