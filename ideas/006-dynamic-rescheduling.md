# Reschedule When Tomorrow Changes

**Status:** Proposed; assistant authority and confirmation flow need discussion.

## Idea

When the next day changes—for example, a class is cancelled, an exam is added, or a social event comes up—the student can tell an AI assistant. The planner then uses the student's priorities to move tasks or propose work for newly free time.

## Questions to resolve

- Should the assistant only suggest a revised plan, or may it apply changes automatically?
- Should the student see and approve every change before the schedule updates?
- How should urgent changes and conflicting commitments be handled?
- What should happen to tasks displaced by a new event?
- Can the assistant ask follow-up questions when it does not know the event duration or importance?
