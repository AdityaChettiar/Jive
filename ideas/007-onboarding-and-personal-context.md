# Onboarding and Personal Context

**Status:** Proposed; sequence and required information need discussion.

## Idea

Start with onboarding that learns what kind of person the user is (for example, a student or working person), gathers their relatively stable weekly commitments, asks about activities and goals, and records how they want to prioritize them. The user can also identify workable time around fixed commitments.

Potential activities include gym, content creation, hobbies, and other pursuits. Priorities may differ between normal available time and newly freed time.

## Questions to resolve

- Is role selection useful, or should onboarding start directly with goals and availability?
- Which information is required to create the first useful plan?
- How should users distinguish fixed commitments from flexible routine items?
- How should users estimate workable time, energy, and desired pace?
- Can users skip sections and complete onboarding over time?
