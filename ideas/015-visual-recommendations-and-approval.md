# Visual Recommendations with Approval

**Status:** Approval requirement and conversational approval agreed; presentation details remain open.

## Idea

When the AI proposes ways to address a problem or adjust a schedule, it should show the possible solutions and explain the pros and cons of each. The comparison should be visually engaging, potentially using color or graphics to make trade-offs easy to understand.

After considering the user's priorities and current situation, the AI should explain which solution it recommends and why it fits best. **The AI must wait for the user's approval of the final set of changes before applying any of them.** The user can discuss and revise the proposed set conversationally; see [Conversational Change Negotiation](016-conversational-change-negotiation.md).

## Questions to resolve

- How should the visual comparison work for accessibility and different screen sizes?
- Which pros, cons, and trade-offs are most useful to compare?
- How should the assistant present uncertainty or explain why its recommendation fits?
